# Meeting-Monster 胶囊与浅色设置页视觉优化设计

日期：2026-08-06

## 目标

在不改变模型、语音转写、共享隐藏和跨窗口同步逻辑的前提下，完成三项桌面端视觉与交互优化：

1. 悬浮胶囊更透明、更紧凑，减少对桌面的遮挡。
2. 设置窗口改为浅灰侧栏与白色内容区，并显著扩大可拖拽区域。
3. 胶囊关闭状态的展开按钮文案由“展开”改为“Chat”。

## 视觉方向

整体采用轻量、克制的桌面工具风格。设置页以浅灰和白色建立层级，蓝色只用于选中、主操作与键盘焦点。胶囊继续保持深色以适配任意桌面背景，但降低遮盖度并缩小几何尺寸。

### 设计令牌

设置页：

- 内容画布：`#FFFFFF`
- 侧栏与次级表面：`#F4F5F7`
- 卡片弱表面：`#FBFCFE`
- 正文：`#171A21`
- 次要文字：`#667085`
- 边界：`#E2E6EC`
- 焦点与主操作：`#2F7CF6` / `#2563EB`
- 成功：`#14855F`
- 警告与错误：`#C65A1E`

胶囊：

- 主背景：`rgba(29, 36, 48, 0.68)`，比当前 `0.86` 更透明
- 按钮背景：`rgba(69, 80, 99, 0.64)`
- 悬停背景：`rgba(93, 107, 131, 0.82)`
- 文字与状态色保持高对比度，不降低文字本身透明度

字体继续使用 `Segoe UI` 与 `Microsoft YaHei`，避免引入新依赖。

## 悬浮胶囊

### 几何

- 胶囊原生尺寸从 `276 × 56` 调整为 `248 × 48`。
- 面板保持 `648 × 450`。
- 胶囊与面板继续保持 `14px` 的视觉间距，因此面板纵向偏移从 `70px` 调整为 `62px`，overlay 固定尺寸从 `648 × 520` 调整为 `648 × 512`。
- 胶囊在 overlay 中水平居中，shape 的 x 坐标由 `186` 调整为 `200`。
- overlay 展开、收起仍只改变 shape，不 resize，不中断转写。

### 密度与控件

- 胶囊内边距收紧，组件间距由 `6px` 适度压缩。
- 头像调整为 `32px`，状态点保持清晰可辨。
- Chat 与退出按钮高度调整为 `30px`，退出按钮为 `30 × 30`。
- 状态文本仍可截断，不允许挤压 Chat 和退出控件。
- 关闭状态按钮显示 `Chat`；展开状态仍显示 `收起`，避免打开后动作含义不清。
- 整个非按钮区域继续作为拖拽区域，按钮保持 `no-drag`。

## 设置窗口

### 布局

设置窗口尺寸、最小尺寸、单实例行为和隐私保护策略保持不变。

窗口使用两列两行网格：

```text
┌──────────────────────────────────────────────┐
│ ×             全宽拖拽标题栏                 │ 42px
├──────────────┬───────────────────────────────┤
│ 浅灰侧栏     │ 白色、独立滚动的内容区        │
│ 品牌与导航   │ 标题、卡片、表单、操作按钮    │
│              │                               │
│ 版本信息     │                               │
└──────────────┴───────────────────────────────┘
```

- 顶部新增 `42px` 全宽标题栏，除关闭按钮外全部为拖拽区域。
- 标题栏背景在侧栏列使用浅灰、内容列使用白色，使两列视觉连续。
- 关闭按钮保留左上角位置，并明确设置为 `no-drag`。
- 侧栏整体仍可拖拽；导航按钮保持 `no-drag`。
- 内容区保持独立纵向滚动，表单、按钮、选择器全部为 `no-drag`。
- 侧栏宽度调整为 `210px`；小尺寸窗口继续通过现有媒体查询收窄。

### 浅色组件

- 活动导航使用白色底、轻边框和蓝色左侧标记。
- 卡片使用近白背景、浅灰边界和极轻阴影，不使用深色大块填充。
- 输入框使用白色背景和灰色边界；focus 使用 2px 蓝色轮廓。
- 主按钮保持蓝底白字；次按钮使用白底深色文字。
- 成功、警告和错误保留语义色，并满足浅色背景下的可读性。
- 滚动条改为浅灰轨道和中灰滑块。

## 组件与代码边界

- `CapsuleApp` 只修改文案，不改变 intent、ASR 状态或退出逻辑。
- `capsule.css` 负责透明度和紧凑密度。
- `overlay-window-controller.ts` 负责新的精确几何与 shape。
- `SettingsApp` 新增纯布局用途的标题栏，不新增 IPC。
- `settings.css` 完成浅色令牌、网格和拖拽区域调整。
- 不新增依赖，不修改版本，不改变 preload 与 IPC 权限边界。

## 可访问性与交互

- Chat 按钮继续暴露 `aria-expanded`。
- 关闭按钮保留明确的中文 `aria-label`。
- 所有交互控件继续支持可见的键盘焦点。
- `prefers-reduced-motion` 规则保持有效。
- 更透明只作用于胶囊背景，不降低文本、状态点或图标的对比度。

## 测试与验收

实施使用 TDD：先更新或新增会失败的测试，再修改生产代码。

自动验证：

- React 测试验证关闭状态显示 `Chat`，点击后仍发送 `toggle-workspace`。
- 静态契约验证胶囊 `248 × 48`、overlay `648 × 512`、面板偏移 `200, 62`。
- CSS 契约验证胶囊背景 alpha 为 `0.68`、按钮尺寸为 `30px`。
- 设置页结构测试验证存在全宽拖拽标题栏，关闭按钮与表单为 `no-drag`。
- 设置页主题测试验证 `color-scheme: light`、浅灰侧栏、白色内容区及浅色语义令牌。
- 运行 unit-test、typecheck、renderer build 与 desktop-test。

视觉验收：

- 胶囊在浅色和深色桌面背景上都明显更少遮挡，同时文字仍清晰。
- 胶囊实际可点击区域与原生 shape 一致，不留下透明但阻挡鼠标的边缘。
- 设置窗口可从顶部大部分区域拖动，也可从侧栏空白区域拖动。
- 设置内容滚动、输入、选择、按钮和关闭操作不被拖拽区域吞掉。
